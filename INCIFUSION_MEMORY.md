# Project Memory

## Current Architecture

1. **Frontend Core:**
   - React 18, Vite, TypeScript, Tailwind CSS, GSAP (ScrollTrigger / ScrollDirector), Framer Motion, Lucide icons.
   - Three.js / React Three Fiber / Drei for persistent WebGL canvas layer (`PersistentStage.tsx`).
   - HTML5 2D Canvas with high-DPI scaling for interactive tactile experiences (`FogMirrorCanvas.tsx`, `FoilScratchCanvas.tsx`).

2. **State Management, Content Configuration & Central Audio Controller:**
   - Single canonical Zustand store (`useExperienceStore.ts`) tracking global progression, audio settings, chapters, and act-specific state (`isBridgeConnected`, `discoveredMemoryIds`, `discoveredMirrorNoteIds`, `mirrorClearedPercent`, `pouredVialIds`, `temperatureCelsius`, `revealedScratchIds`, `isHoldingFingerprint`, `heartbeatCompleted`, `cakeAssemblyStep`, `isCandleExtinguished`, `birthdayWishText`, `isLanternReleased`, `isLetterSealBroken`, `vipRedemptions`, `currentChapter`).
   - Centralized content & media manifest (`src/data/storyData.ts`, `src/types/story.ts`, re-exported via `src/config/storyContent.ts` and `src/types/story.types.ts`) containing `PHOTO_PATHS` (`/photos/*.jpg`), 10-track `SOUNDTRACK_MANIFEST` (`/audio/*.mp3`), grounded Long-Distance Relationship (SYG) story data for Uci (`cinta`, `cintaku`, `Sayang`), and `telegramUsername` (default `'YOUR_TELEGRAM_USERNAME'`, without `@`).
   - Authoritative `HTMLAudioElement` soundtrack & lifecycle controller (`src/utils/musicController.ts`) managing 10 local Mixkit Free Stock Music MP3s in `public/audio/` with cosine crossfades, act-aware procedural audio cleanup (`proceduralAudio.stopAllActiveLoops()`), Act VII candle-blow audio ducking (`playBirthdayCandleSequenceOnce()`), Final Poem outro synchronization (`playFinalPoemOutroOnce()`), active vinyl scratching (`scratchActiveVinyl()`), and a single global `SOUND ON` / `SOUND OFF` button in `SoundControlPill.tsx`.
   - Transient motion store (`transientMotionState.ts`) for 60fps frame loop variables without triggering React re-renders.
